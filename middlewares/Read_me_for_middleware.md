## Проверка подписки на канал

Функция `is_subscribe` проверяет, состоит ли пользователь в канале. Она использует кэш, чтобы не перегружать API Telegram лишними запросами.

### Как это работает

1. **Сначала смотрим в кэш.** Функция проверяет, есть ли уже сохранённый статус для этой пары `chat_id:user_id`.
2. **Если статус есть — верим ему.** Неважно, `True` это или `False`. Мы сразу возвращаем сохранённое значение и **не делаем запрос к Telegram**. Это защищает бота от лимитов.
3. **Если статуса нет — спрашиваем у Telegram.** Только в этом случае бот делает запрос `get_chat_member`.
4. **Сохраняем результат в кэш** с разным временем жизни (TTL) в зависимости от статуса.

### Важные нюансы (почему сделано именно так)

| Статус пользователя | Время хранения в кэше (TTL) | Зачем так |
| --- | --- | --- |
| **Подписан** (`True`) | 300 секунд (5 минут) | Подписчикам статус не нужно обновлять часто. Это снижает нагрузку на API. |
| **Не подписан** (`False`) | 10 секунд | Позволяет пользователю быстрее увидеть актуальный статус после подписки (без кнопки сброса кэша). |

> ⚠️ **Важно для пользователя:** Статус обновляется не мгновенно. Если пользователь только что подписался, ему нужно подождать до 10 секунд, пока кэш обновится. Бот должен явно предупреждать об этом.

### Логика функции (ключевой момент)

Критически важно, что функция **не делает запрос к API**, если в кэше уже есть любое значение. Проверка идёт только по условию `if cached is not None`. Это гарантирует, что даже при частых нажатиях кнопок бот не превысит лимиты Telegram.

Разные TTL используются только на этапе сохранения результата, но не влияют на частоту запросов — запрос делается только один раз, пока кэш не истечёт.

### Пример использования

```python
from utils.subscription import is_subscribe

async def handle_start(message):
    if await is_subscribe(message.bot, CHANNEL_ID, message.from_user.id):
        await message.answer("✅ Добро пожаловать! Вот твоё меню...")
    else:
        # Обязательно предупреждаем про задержку!
        await message.answer(
            "⚠️ Ты не подписан на наш канал.\n\n"
            "Подпишись по ссылке: [ссылка на канал]\n\n"
            "🕒 Статус обновляется автоматически каждые 10 секунд. "
            "Если ты только что подписался — просто подожди немного."
        )
